Cheap checks first. The AI never has the last word.

02 · GEMMA (AMD)

03 · MARKING CHECK

04 · DECISION

Deterministic rules — not the LLM — own the verdict.

FAIL-SAFE

If the model ever goes down, Spillguard degrades to a safe verdict instead of failing. Engineering discipline, not a single prompt.
