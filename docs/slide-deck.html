The problem

Secret data leaks — and the tools can't stop it.

  • Defense contractors must protect Controlled Unclassified Information (CUI) — law: DFARS 7012 / CMMC 2.0.
  • A leak — a "spillage" — is a reportable, contract-ending event.
  • Legacy DLP is just keyword matching — it misses anything it wasn't told to look for.
The insight

An AI security tool that inspects your document by sending it to a cloud AI has already committed the leak it exists to prevent.

You cannot prevent a spillage by committing one. Every cloud-based "AI DLP" is disqualified.

The solution

Spillguard inspects every document at the door.

…with the AI (Google's Gemma) running on your own AMD GPU, on a network with no route to the internet. The document never leaves the box.

How it works

Cheap checks first. The AI never has the last word.

1 · Deterministic

Regex/keyword checks run first & always — also our "legacy DLP" baseline.

2 · Gemma (AMD)

Self-hosted Gemma reads the meaning — catches unlabeled secrets.

3 · Marking check

Compares markings the doc has vs. what its content requires.

4 · Decision engine

Deterministic rules — not the LLM — own the verdict. Model down? It degrades to a safe verdict instead of failing.

Use of AMD

Gemma 3, self-hosted on AMD — the reason it works.

  • Gemma 3 (12B) served on an AMD Instinct GPU via ROCm + vLLM.
  • The GPU's memory holds the entire CUI ruleset in-context — no fine-tuning.
  • Air-gap enforced by an internal-only network — the model has no route out.
  • Self-hosting on AMD isn't bolted on — it's the only way this product can legally exist.
